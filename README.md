# E-Commerce Orders Data Analysis using SQL

## 1. Project Overview
This project focuses on analyzing e-commerce business data using SQL.
The objective is to extract meaningful business insights related to
sales, revenue, customers, products, payments, and returns.

## 2. Tools and Technologies
- SQL
- DuckDB
- DBeaver
- Excel (for viewing exported results)
- CSV

## 3. Database Description

The database contains seven tables:

- customers
- products
- categories
- orders
- order_items
- payments
- returns

Total records: 426,024

## 4. SQL Analysis Performed

The following analyses were performed:

1. Revenue by Category
2. Monthly Revenue and Orders
3. Category-wise Profit
4. Profit Margin Analysis
5. Monthly Revenue Analysis
6. Top 10 Products / Customers
7. Order Status Analysis
8. Returns Analysis
9. Payment Method Analysis
10. Shipping Country Analysis
11. Sales Channel Analysis
12. Overall Business KPIs

## 5. Key Business Findings

- Furniture recorded the highest profit margin of 42.67%.
- The Web channel generated the highest revenue.
- Heritage Steel Trowel was the top-selling product.
- Card was the leading payment method by payment value.
- Delivered orders represented the largest order-status category.

## 6. Project Files

- `ecommerce_analysis.sql` – SQL analysis queries.
- `ecommerce_orders.schema.sql` – Database schema.
- `ecommerce_orders_load.sql` – Data loading script.
- `results/` – Exported CSV analysis results.
- `data/` – Original dataset files.

## 7. Conclusion

This project demonstrates practical SQL skills, including joins,
aggregations, grouping, filtering, calculations, and business data analysis.
